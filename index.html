Embed code

Download for hand-off saves a single HTML file: open it in a browser to check the invitation works, and send it on — the embed snippet is marked inside for whoever adds it to the site. Copy share link gives a URL that reopens this builder with every setting and the details copy already filled in.

Paste the snippet wherever the invitation should appear. Append ?name=Jane%20Doe to the page URL sent to each guest and their name is hand-lettered onto the envelope. The embed loads its own styles in a shadow root, so it will neither inherit nor disturb the host page's CSS.
